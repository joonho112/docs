Public Code, Private Data: Lessons From an Open-Source Pipeline for Alabama’s Confidential Pre-Kindergarten Records

JoonHo Lee, Alison Hooper, and Tammy Walker · August 2026

Abstract

State pre-kindergarten programs generate detailed administrative records, and those records inform evaluation and funding decisions. The processing that turns raw agency files into research-ready data receives far less attention: in many university–agency partnerships it consists of one analyst’s private scripts, an arrangement that survives neither staff turnover nor routine changes to the agency’s reporting formats. Drawing on five years of experience working with Alabama’s First Class Pre-K administrative records, this article describes an open-source approach to processing confidential data that emerged from that experience. Working with the Alabama Department of Early Childhood Education, we moved the processing of confidential budget, classroom, and student records into ALprekDB, an open-source R package built on a simple rule (public code, private data): the cleaning rules, validation checks, tests, and documentation are all public, the records themselves never leave the secure environment, and synthetic data allow anyone to run the full pipeline without seeing a real record. Two events tested the design. The state’s wholesale rebuild of its reporting formats was absorbed through mapping files that agency staff can read, with no changes to code. When a vendor delivery later arrived with contracted fields blank, the validation framework missed it; the fault-injection audit that followed detected eight of twelve seeded fault classes. We report the misses alongside the catches and draw practical lessons for agencies and research partners contemplating the same move.
